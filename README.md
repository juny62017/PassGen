# PassGen

A soft and aesthetic password generator and password strength checker built by me....

## Description

PassGen is a website that helps you to generate secure passwords and check password strength in real time. 
The project focuses on clean design and useful eatures.....

## Features

- Generate random passwords
- Adjustable password length
- Uppercase letter option
- Lowercase letter option
- Number option
- Symbol option
- Live password strength checker
- Animated bar
- Copy password button

## How To Use

- Visit The website 
- tick the boxes of your choice 
- and click on generate it 

  2nd feature 
  
- Type Your old password and it will tell you in real time if its weak strong or medium
